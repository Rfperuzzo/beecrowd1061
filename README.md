# ⏱️ Beecrowd 1061 — Tempo de um Evento

Solução desenvolvida em **Java** para o exercício **1061 — Tempo de um Evento**, da plataforma Beecrowd. O problema pede o cálculo da duração completa de um evento em **dias, horas, minutos e segundos**. :chatgpt-content-reference{index="0"}

---

## 📚 Objetivo

Este exercício trabalha principalmente com:

- Entrada de dados;
- Variáveis do tipo `int`;
- Operações matemáticas;
- Conversão de unidades de tempo;
- Uso de divisão inteira;
- Uso do operador de resto `%`;
- Cálculo de diferença entre dois momentos.

---

## 🧠 Lógica do problema

O programa recebe:

- Dia inicial;
- Hora, minuto e segundo iniciais;
- Dia final;
- Hora, minuto e segundo finais.

Uma forma prática de resolver o problema é converter todos os valores para **segundos**.

Exemplo:

```text
1 dia = 86400 segundos
1 hora = 3600 segundos
1 minuto = 60 segundos
